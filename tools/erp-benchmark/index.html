ERP-Benchmark

ERP-Benchmark is a datasets & benchmarks tool whose code is published by DL4mHealth on GitHub, first public in 2026, described in IEEE Transactions on Biomedical Engineering (2026). Unified benchmark of 15 methods (manual ERP features, deep learning trained from scratch, and pretrained EEG foundation models) on stimulus classification and brain-disease detection across 12 public datasets.
