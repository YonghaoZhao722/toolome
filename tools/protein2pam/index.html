Protein2PAM

Protein2PAM is a crispr & gene editing tool whose code is published by Profluent-AI on GitHub, first public in 2026, described in Nature Biotechnology (2026). Profluent's protein language model that predicts a Cas enzyme's PAM specificity from its sequence and guides PAM-engineering of Cas9 variants.
