ProDiT

ProDiT is a protein structure & design tool whose code is published by bjing2016 on GitHub, first public in 2026, described in Nature Machine Intelligence (2026). Multimodal diffusion transformer (ProDiT) that jointly generates protein sequence (discrete diffusion) and structure (continuous diffusion), conditioned on Gene Ontology molecular-function terms, with a multistate sampling protocol for designing proteins with multiple functional states (e.g. allosterically deactivatable active sites).
