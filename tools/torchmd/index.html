TorchMD

TorchMD is a drug discovery & molecules tool whose code is published by torchmd on GitHub, first public in 2020, described in Journal of Chemical Theory and Computation (2021). PyTorch molecular dynamics engine that mixes classical force fields with neural network potentials.
