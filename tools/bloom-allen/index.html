Bloom (Allen Institute)

Bloom (Allen Institute) is a single-cell & foundation models tool whose code is published by AllenInstitute on GitHub, first public in 2026, described in bioRxiv preprint (2026). Allen Institute cell foundation model that embeds single-cell RNA and ATAC profiles into a shared 1,024-d space, trained on whole mouse brain data; inference CLI for cell embeddings.

Can I use Bloom (Allen Institute) commercially?

Partly. The code and the weights (or hosted service) are under different terms; the restrictive part does not allow commercial use.
