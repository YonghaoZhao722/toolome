HEST

HEST is a spatial omics tool whose code is published by mahmoodlab on GitHub, first public in 2024, described in arXiv preprint (2024). HEST-1k dataset of 1,276 paired spatial transcriptomics and H&E whole-slide samples, plus a library and benchmark for histology foundation models.
