Sniffles2

Sniffles2 is a sequencing & variant calling tool whose code is published by fritzsedlazeck on GitHub, first public in 2022, described in Nature Biotechnology (2024). Fast structural-variant caller for long reads with population-scale and mosaic SV detection.
