MetaCAT

MetaCAT is a microbiome & metagenomics tool whose code is published by liu-congcong on GitHub, first public in 2026, described in Nature Microbiology (2026). Metagenome binning plus microbial SNP calling and metagenome-wide association with host traits in one framework.
