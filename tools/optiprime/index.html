OptiPrime

OptiPrime is a crispr & gene editing tool whose code is published by alvin-hsu on GitHub, first public in 2026, described in Nature Biotechnology (2026). David Liu lab's mechanistic ML model that predicts prime-editing efficiency and outcomes for PE2, PE3 and twinPE, with a web server.
