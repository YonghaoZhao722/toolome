Chaperone

Chaperone is a bio llm agents & copilots tool whose code is published by RosettaCommons on GitHub, first public in 2026, described in bioRxiv preprint (2026). Baker lab harness that wires 50+ protein design, folding and analysis tools into reproducible SLURM pipelines and ships agent skills so coding agents can build and run design campaigns.
