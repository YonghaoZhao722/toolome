MaSIF

MaSIF is a protein structure & design tool whose code is published by LPDI-EPFL on GitHub, first public in 2019, described in Nature Methods (2020). Geometric deep learning on protein molecular surfaces to predict interaction sites, ligand pockets and binding partners.
