DeSCENT

DeSCENT is a clinical & biomedical llms tool whose code is published by YonghaoZhao722 on GitHub, first public in 2026, described in Bioinformatics (2026). Generates reference-informed single-cell profiles from bulk RNA-seq for cancer survival prediction; on eight TCGA cohorts, average C-index improved versus a bulk-only baseline, while integrated Brier scores were mixed.
