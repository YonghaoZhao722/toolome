OMol25

OMol25 is a datasets & benchmarks tool whose code is published by facebookresearch on GitHub, first public in 2025, described in arXiv preprint (2025). Meta FAIR's open dataset of DFT calculations on diverse molecules, with evaluations and baseline models.
