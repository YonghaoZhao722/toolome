AlphaPeptDeep

AlphaPeptDeep is a proteomics & metabolomics tool whose code is published by MannLabs on GitHub, first public in 2022, described in Nature Communications (2022). Deep learning framework predicting peptide MS2 spectra, retention time and CCS for proteomics.
