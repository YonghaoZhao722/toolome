License types

Each tool's label is derived from the code and weights licenses recorded in our data, with a link to the source on its page. Model weights often have a different license from the code, so check both.

LabelTypical licensesWhat it allowsTools
Permissive (commercial OK)MIT, Apache-2.0, BSD, CC-BY-4.0, CC0Use, modify and ship inside closed-source commercial products. Keep the license text and copyright notices; Apache-2.0 also includes a patent grant.192
Copyleft (commercial OK, share-alike)GPL-3.0, AGPL-3.0 (strong); LGPL-3.0, MPL-2.0 (weak)Commercial use is allowed. If you distribute a modified version or a combined program, the source must be released under the same license. AGPL also covers software offered as a network service. Weak copyleft (LGPL, MPL) applies only to the licensed files or library, so your own code that uses it can stay closed.17
Proprietary (paid or negotiated license)Vendor termsCommercial products and services. Use is governed by a paid or negotiated agreement with the vendor.23
Non-commercialCC-BY-NC, PolyForm Noncommercial/Strict, academic-only licensesNon-commercial use only; some (e.g. academic-only) are narrower. Commercial use needs a separate license from the owner, if one is offered.28
Mixed (code vs weights differ)e.g. Apache-2.0 code + non-commercial weightsThe code and the trained model weights (or hosted service) carry different licenses. Typically the code can be used commercially but the weights cannot, so you would need to train your own weights or get a license.8
UnknownNo license stated, custom terms, or conflicting statementsWe could not confirm the terms from a primary source. Treat as not cleared for commercial use until you check with the authors.34
