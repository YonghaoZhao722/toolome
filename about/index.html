About Toolome

Toolome is a directory of AI tools for biology: 307 tools across 16 categories, each with its links, license, commercial-use status and paper in one place.

Who curates it

Toolome is curated by The Toolome team. Contact: toolome.bio@gmail.com. Corrections and suggestions go through GitHub issues or the submit page.

Non-commercial and open data

  • The site code and the full dataset are public in the GitHub repository (dataset: src/data/tools.json).
  • No ads, no analytics or tracking scripts, no affiliate links, and no paid or sponsored listings. No account is needed to browse.
  • Inclusion is editorial, not paid. The full rules are in INCLUSION.md.

How tools are verified

  • Only verified tools are listed. A tool is added only when its URL can be confirmed. Work under anonymous review is not listed.
  • AI is required. The tool's core method must use machine learning, or it must be a dataset or benchmark built for ML.
  • Facts come from primary sources. The license and commercial-use status come from the tool's repository (via the GitHub API). The paper, venue and year come from the paper itself (via Crossref or arXiv). The first public date is the earliest of the preprint, paper or repository creation date.
  • Links are checked daily. An automated link check runs every day. A tool's "last checked" date is updated only when all of its links respond.
  • No benchmark claims. Comparison pages report what each project states and link to the papers for evaluations.

Update cadence

New tools are reviewed and added daily. Repository status (for example archived repos) and GitHub stars are refreshed weekly. The full list is also available as llms.txt and in the sitemap.
